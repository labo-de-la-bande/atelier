# L'atelier des données du Labo de la Bande

Ce dépôt n'est qu'une salle d'attente. Des collaborateurs invités y modifient des tables du jeu depuis la page de l'atelier (https://labo-de-la-bande.github.io/jeu/atelier.html), par le relais du projet ; l'auteur relit et verse ces modifications dans le dépôt du jeu (`labo atelier fusionner`). Chaque commit dit qui a changé quoi, et pourquoi.

`.base/` garde la version du dernier envoi : la base de la fusion.
